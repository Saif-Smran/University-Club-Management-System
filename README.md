# University Club Management System

This repository contains the planning and requirements documentation for the University Club Management System (UCMS).

## Project Structure

- `University_Club_Management_System_Requirements.md` - Master requirements document for the overall system.
- `Backend/` - Backend-related requirements and implementation planning.
  - `UCMS_Backend_Requirements.md`
- `Frontend/` - Frontend-related requirements and implementation planning.
  - `UCMS_Fronted_Requirements.md`

## Purpose

The UCMS project is intended to manage university clubs, including operations such as membership management, event coordination, and communication workflows.

## Getting Started

1. Start by reading the root requirements document:
   - `University_Club_Management_System_Requirements.md`
2. Review backend and frontend requirement files for module-specific details.
3. Use these documents as the source of truth while implementing the application.

## Notes

- This repository currently focuses on requirements and planning artifacts.
